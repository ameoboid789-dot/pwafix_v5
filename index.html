ระบบกลาง Supabase

ใบงาน ข้อมูลหลัก และรูปภาพใช้ฐานข้อมูลกลาง ต้องเข้าสู่ระบบด้วยบัญชีที่ได้รับอนุญาต

เริ่มต้น: ตั้งค่า Supabase ตามคำแนะนำด้านล่าง

วิธีตั้งค่าครั้งแรก
  1. เปิด Supabase Project → SQL Editor แล้วรัน SQL ด้านล่าง
  2. Authentication → Users → Add user สร้างบัญชีอีเมล/รหัสผ่านของผู้ใช้แต่ละคน
  3. คัดลอก User UID แล้วรัน: insert into public.pwa_members(user_id) values ('USER_UID');
  4. นำไฟล์ HTML นี้ขึ้นเว็บ HTTPS แล้วเข้าสู่ระบบ ทุกบัญชีที่เพิ่มไว้เห็นและแก้ไขข้อมูลชุดเดียวกัน

ข้อมูลเก่าในเครื่องยังอยู่ แต่ไม่ถูกนำขึ้นเซิร์ฟเวอร์เอง หากต้องการนำเข้า ให้กดปุ่มหลังเข้าสู่ระบบ การนำเข้าจะไม่ทับใบงาน ID เดิม
